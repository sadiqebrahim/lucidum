AI models that write code are now also finding the holes in it. OpenAI has released GPT-6 Cyber, a model built for security research. The headline numbers, all from OpenAI and [reported by BleepingComputer](https://www.bleepingcomputer.com/news/security/openais-new-gpt-6-cyber-ai-finds-81-firefox-flaws-948-linux-bugs/) and [The Next Web](https://thenextweb.com/news/openai-gpt-6-cyber-launch-firefox-linux-daybreak-red), show how quickly that capability is growing.

## Find, prove, fix

GPT-6 Cyber is designed to find software vulnerabilities, check that they're real and exploitable, and help developers write fixes.

## What it found

In Firefox, OpenAI says the model found <mark>81 previously unknown high-severity flaws</mark>, with patches developed partly by the model; Mozilla has started releasing them.

In the Linux kernel, it identified 2,308 potential flaws, reproduced 1,724 vulnerabilities, and built working local privilege-escalation exploits for 948 of them: attacks that could take an unprivileged user to full root control. With the same setup, an earlier OpenAI model managed 166. OpenAI says it has disclosed 304 critical Linux findings to maintainers, with proposed patches.

*OpenAI's count for Linux: flaws reproduced and working attacks built.*

On ExploitGym, a benchmark of whether a model can exploit a given flaw, it scored 48.5%, against 32.1% for GPT-5.6 Cyber.

## Rated Critical

Because of these capabilities, OpenAI rates the model "Critical" for cybersecurity under its Preparedness Framework, up from "High" for its previous cyber model. Access is limited to vetted customers in its Daybreak Red programme. In a test designed to tempt the model into attacking off-limits systems, it stayed in scope 99.93% of the time without its safety prompt (94.49% for the previous model), and every time with it.

## Patching can't keep up

Chris Hughes of Noma Security told CSO that even a small fraction of out-of-scope actions matters at this scale, and noted that OpenAI's Patch the Planet dashboard shows fewer than 25% of flaws fixed so far.

## The catch

Every capability figure here comes from OpenAI itself and hasn't been independently verified. Finding flaws faster helps defenders only if the fixes keep pace.
